# STRATUM BOOK UNDERSTANDING 2.0 - CURRENT STATE MAP

## A. Knowledge / A 仓 (AII_KG)
- `aii.ku_onto`: CURRENT_PRODUCTION. Written by python scripts (`math_ingest.py`, `synthesize_book.py`). 
- `aii.concept_onto`, `aii.edge_onto`: CURRENT_PRODUCTION.
- `stratum.knowledge_claims`, `stratum.evidence`: SCHEMA_ONLY / IMPLEMENTED_UNUSED. Exist in `src/stratum/db/pg_migrations/020_knowledge_graph_unification.sql` and used by `src/stratum/api/routers/knowledge.py`, but the main book ingest pipeline still uses `aii` schemas.

## B. Book Understanding (BU)
- `aii.bu_onto`: CURRENT_PRODUCTION. Generated by `generate_bu.py` and `persist_bu.py`. Contains rich fields: `learning_paths`, `deep_cards`, `bu_quality`, `facets_grounded`, `agent_skill`, `embedding`, `overview_oneline`, `learning_thread`, `main_claims`, `argument_structure`. 
- Book flywheel scripts (`flywheel_single_book.sh`, `synthesize_book.py`) process whole books.
- The BU generation has multiple fields but text-heavy schemas.
- `Argument` model: TEXT_ONLY / PARTIAL_STRUCTURE in `argument_structure` JSON/text. No formal database tables.
- `ChapterUnderstanding`: SUMMARY_ONLY.

## C. Notes / Expression
- `cornell_notes`: CURRENT_PRODUCTION. Written by `src/stratum/api/routers/cornell.py`. Machine notes generated from B repo concepts (`refined_concept_ids`).
- `cornell_progress`: CURRENT_PRODUCTION. Synchronizes local UI progress.

## D. Learning / C 仓 (AII_CONTEXT)
- `cx.learning_progress`: CURRENT_PRODUCTION. Uses C-warehouse (`aii_context`) database. Tracks `grade`, `pending_quiz`, `b_repo_ku_ids`, `next_review_at`.
- Flashcards (`stratum.flashcards`): CURRENT_PRODUCTION. Bypasses KU entirely, uses `oprim.llm.llm_call` on raw text. Uses FSRS/SM-2 scheduler inside `flashcard_service.py`.
- UI `LearningLayer.tsx`: Uses `localStorage` for `done`/mastered state! UI_COMPLETION_NOT_MASTERY.

## E. Website / API
- `AII Service Layer`: Port 9304.
- Frontend Next.js app in `aii-web`.

## F. Runtime / Storage / Authority
- **Dual Track Architecture**: Real pipelines write to `aii_kg` and `aii_refined` (B repo) databases. The new Stratum APIs (in `src/stratum/`) define a `stratum` schema that is essentially a new architectural contract missing the core data volume.
