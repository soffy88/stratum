# Linear Function

A **linear function** is a function whose graph is a straight line and whose output changes at a constant rate with respect to the input. In junior high mathematics, it is usually written in the form

\[ y = kx + b \]

where:
- **k** is the slope or rate of change
- **b** is the y-intercept

When **k ≠ 0**, the graph is a non-horizontal straight line. A special case is the **proportional function** \(y = kx\), which passes through the origin.

## Core ideas

### 1. Formula and meaning
- The coefficient **k** tells how much y changes when x increases by 1.
- The constant term **b** tells where the graph crosses the y-axis.
- If two points on the graph are known, the function can often be determined by substitution.

### 2. Graphical properties
- A linear function graphs as a straight line.
- Its slope determines whether the line rises or falls:
  - **k > 0**: increasing
  - **k < 0**: decreasing
  - **k = 0**: constant function
- Graphs can be shifted horizontally or vertically, and the result is still linear.

### 3. Real-world applications
Linear functions are useful for describing situations with a fixed starting value and a constant rate, such as:
- taxi fare pricing
- fuel consumption
- travel distance and time
- production and cost
- temperature or water-level changes under steady conditions

## Important problem-solving patterns

### Determine a function from two points
Given two points \((x_1, y_1)\) and \((x_2, y_2)\), substitute both into \(y = kx + b\), then solve the system.

### Use intercepts carefully
If a line crosses the axes at known points, those intercepts can directly reveal the equation.

### Translate a real situation into a function
The source document repeatedly turns text descriptions into expressions like:
- starting fee + distance-based fee
- fixed output rate × time + initial amount
- different rules for different ranges

### Compare two linear functions
To decide which function is larger, set them equal or compare their difference over an interval.

## Connections

Linear functions connect naturally to statistics when analyzing trends, and to geometry when representing coordinates or distances. They also share a strong relationship with [[concepts/pythagorean-theorem]] in coordinate geometry problems, though they are studied here mainly as algebraic models.
